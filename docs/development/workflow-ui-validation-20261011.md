本轮把普通对话、任务编排、Agent 抽屉和插件状态当作同一任务壳进行复核。改动分三批完成：Agent 业务摘要与抽屉视图；任务模式切换、交接卡片与侧栏任务聚合；插件诊断、恢复状态和禁用后的只读体验。

## 通过项

- 已完成 Agent 默认打开成果、运行中显示活动和工作动画、失败/阻塞显示概览，执行过的活动项默认折叠。
- 活动日志沿用同一条流，用户阅读历史时新增活动只显示“新增 N 条活动”，不会强制跳到底部。
- 对话切换与编排切换保留任务上下文；相邻同一工作流版本的交接合并为一张卡片并保留历史，来源不同或被普通消息打断时保持独立。
- 任务模式读取、维护请求、创建任务和工作流程实例化均带有请求代次校验。迟到响应不会覆盖新任务、新目录或新草稿。

- 桌面保留画布布局；窄屏改为纵向节点列表，抽屉在窄屏保持视口内并支持 Escape 关闭。
