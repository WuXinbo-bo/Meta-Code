# 工作台 UI 与交互规范

工作台围绕项目、临时对话和当前阅读内容组织界面。此层只管理呈现、导航草稿与用户操作；Agent 执行、Provider 合同、任务编排和日志存储沿用现有实现。

## 界面结构

1. 左侧统一展示进行中、置顶、项目任务和最近临时对话。项目设置、任务文件夹和归档恢复在同一侧栏提供入口。筛选项目只改变列表，不切换当前对话。
2. 普通新任务默认临时对话；从项目行或项目菜单新建时显式带入该项目，主 Agent 初始为空。位置、任务类型和 Agent 采用图标控件，保留可访问名称、选择反馈与键盘操作。用户选择的草稿位置是创建目标；编排仍要求项目。
3. 对话阅读宽度与字体由设计变量统一控制；主对话与子 Agent 共用回复和活动呈现。收窄正文不能裁切代码、文件预览或移动端输入区。
4. 桌面顶栏按任务标题、浏览器页签和操作约 1:2:1 分配宽度；省去重复的临时目录入口。Token 统计放在任务详情中，移动端把连接状态收进更多操作。
5. 桌面常驻浏览器式横向页签，小屏通过紧凑入口打开页签浮层。保留固定、关闭、恢复、搜索、拖动排序和返回对话。页签不挤压正文；点击和键盘操作可以进入辅助浮层。
6. 右侧纵向活动入口只显示被调用的子 Agent；全部完成后收缩为历史入口。完成和运行中的日志均可打开，手动展开的工具详情不因完成状态变化或浮层交互丢失。
7. 文件区默认收起，悬停或点击文件图标显示，可固定。目录更新显示时间与刷新图标；搜索默认收起。文件搜索复用现有工作区 API，提供防抖、取消、失败重试和范围上限提示；保留目录展开状态与原文件操作。

## 交互边界

- 浮层通过 Portal 避免侧栏和顶栏裁切，定位受视口约束。菜单移动、窗口缩放和滚动后仍跟随入口。
- Escape 优先关闭当前浮层并还焦，不能连带关闭外层新任务弹窗。菜单动作关闭后只在焦点丢失时还焦，不抢新弹窗的焦点。
- 已选 Agent 变未就绪时保留选值，其他可用 Agent 仍能通过键盘选择；不引入全局默认主 Agent。
- 搜索响应必须匹配当前工作区与查询；旧请求取消或晚到时不能覆盖新结果。隐藏文件面板暂停周期刷新，重新显示时刷新现有缓存。
- 浅色、深色和减少动画设置共用主题变量；减少动画不能影响状态反馈或操作可用性。
- 所有运行指令和工具详情默认折叠，包括执行失败。运行转完成或失败不自动展开，也不清除用户手动展开或收起的状态；失败与成功使用同一灰色色调，失败文字、退出码和原始输出仍可手动查看。主进程与子 Agent 共用日志尾部工作指示。默认隐藏会话创建和开始运行提示，检视筛选保留完整原始活动。
- 新任务面板使用任务类型分段、品牌 Agent 选择卡和独立项目位置条。创建前不预选主 Agent；创建请求失败时保留选项、草稿和面板，在原位显示错误并允许重试。键盘选择、焦点循环、目录入口及编排必须指定项目的约束沿用现有行为。
- 子 Agent 的名称、Provider、规范身份、模式与终态必须在大日志响应摘要中保留；抽屉详细日志单独读取。内部委派等待屏障不显示为真实子 Agent 卡片或活动图标，原始屏障事件仍保留在后端记录中。

## 验证

运行 `npm run typecheck`、`npm run build`，以及 `test:session-creation`、`test:session-navigation`、`test:workspace-browser-tabs`、`test:responsive-inspector`、`test:ux-foundations` 和 Agent 活动相关测试。

视觉验收应使用隔离或模拟数据，检查桌面、768px 和 390px 窗口、浅深主题、项目菜单、新任务、页签、文件搜索和运行／完成的子 Agent 日志。检查几何边界、键盘还焦、请求取消、历史展开状态与隐藏面板刷新；截图后人工确认布局。使用模拟时钟验证轮询后，应在无模拟时钟的独立浏览器上下文中复验视口定位。

日志折叠可使用 `scripts/fixtures/activity-disclosure-ui.html` 与 `scripts/check-activity-disclosure-browser.js` 在真实浏览器检查主对话／子抽屉、运行转失败、手动状态、浅深色与虚拟化重挂载。夹具仅使用合成日志，不写入工作台用户数据。
